WINTER ARC — iPHONE INSTALLATION

This folder is a Progressive Web App (PWA).

1. Upload ALL files in this folder to a web host that serves HTTPS.
2. Open the site's address in Safari on your iPhone.
3. Tap Share.
4. Tap "Add to Home Screen".
5. Tap "Add".

The app can then launch from your Home Screen like an app and works offline after its first successful load.

IMPORTANT:
- Do not open index.html directly from Files if you want installation; PWA installation requires a website served over HTTPS.
- GitHub Pages is a free option.
- Your tracker data is stored locally in the browser on your device.

Files:
- index.html — app
- manifest.webmanifest — install metadata
- sw.js — offline support
- icon-192.png / icon-512.png — app icons
